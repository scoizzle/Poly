## Issues

### Issue 1 -- Severity: bug
- File: `Poly/DomainModeling/Lowering/EffectLoweringPass.cs:424-436`
- Description: Pattern assign guard always emits `Regex.IsMatch(valueRef, pattern)` with no null check. A null Text RHS (reachable via `InvokeAction` parameter dictionary) throws `ArgumentNullException` instead of `DomainResult.Failure("'…' does not match the required pattern.")`. `ValidateConstraints` (`DomainEntityInstance.cs:201-203`) only pattern-checks when `v is string`, so null skips. Empty string still fails pattern (aligned). Create factory (`DomainToCSharpExporter.Notify.cs:433-446`) has the same bare IsMatch shape — assign copied that hole into the shared simulate/print tree.
- Suggestion: Guard like ValidateConstraints: only run IsMatch when value is non-null (e.g. `valueRef != null && !Regex.IsMatch(...)`), and return the pattern Failure message — never throw. Add `PatternAssign_Null_IsFailureOrSkipped` asserting no `ArgumentNullException` and prior value retained. Align Create factory in a follow-up if desired.
- Status: open

### Issue 2 -- Severity: suggestion
