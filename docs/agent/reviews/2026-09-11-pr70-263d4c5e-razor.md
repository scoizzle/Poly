### 2. `HasErrors` flag vs `ShouldInclude` filtering

`AnalysisDiagnosticConfiguration.ShouldInclude`: every verbosity mode includes `Error` (`All`, `InformationAndAbove`, `WarningAndAbove`, `ErrorOnly`). **Filtering cannot drop an Error without also skipping the flag** — the filtered-out severities are Hint/Information/Warning only, which never set `HasErrors`.
