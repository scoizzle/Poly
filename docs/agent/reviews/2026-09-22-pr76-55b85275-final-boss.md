### Issue 1 (F1) -- Severity: suggestion

- File: `Poly/DomainModeling/Compile/DomainSession.cs:168-170` (with `:151-154`)
- Description: Confirmed. `Emit` throws on `ArtifactCatalog.Count == 0`, but `Lower` unconditionally assigns a one-entry list before `Emit` reads the catalog; `ArtifactCatalog` is `private set` with `:152` the sole writer. After `GetOrLower` returns, `Count==0` is unreachable; if `GetOrLower` throws, the check never runs. The fail-closed claim is theater on the only existing call path; reachability is **unreachable on valid and corrupt trees** after Lower returns.
- Suggestion: Delete the dead throw, or make `Lower` omit/clear the catalog on an empty module / failed Lower and add an oracle that forces `Count==0`. Prefer an earlier rung: type the post-Lower state so `Emit` cannot observe an empty catalog.
- Status: open

### Issue 2 (F2) -- Severity: suggestion

- File: `src/Poly.DslCompiler/MinimalApiGenerator.cs:1131-1134` and `Poly.Tests/DomainModeling/Compile/SliceCProducerLoopCatalogTests.cs:139-144`
- Description: Confirmed. NoOp gate is `http is null && storage is null`; http-null + storage-present still emits `Program.cs` + `demo.http`. Reachability checked: on the Compile path the contributor is registered only when the `http` id is loaded, and `HttpSurfacePass` (`HttpSurfaceMetadata.cs:13-16`) always publishes the bag for a `Domain`, so this sibling is unreachable through `Compile`; it is reachable through direct `Contribute`/`AddArtifactContributor` (harness) and that is asserted as intentional by `HostContributor_ParentWithProducedBillingContract_...`. `SliceC_MinimalApiContributor_NoHttpBag_NoOps` only forces the both-null branch, so the PR claim "NoOp without bags" is broader than the oracle.
- Suggestion: Fail-closed when http is null (harness must seed `HttpSurfacePass`/`uses http`), **or** rename the claim/test to "NoOp only when both HTTP and storage bags absent" and add an oracle that forces http-null + storage-present.
- Status: open
