## Issues

### Issue 1 -- Severity: suggestion

- File: `Poly/DomainModeling/Compile/DomainSession.cs:168-170` (with `:151-154`)
- Description: Emit claims fail-closed when `ArtifactCatalog.Count == 0`, but `Lower` unconditionally assigns a one-element SyntaxModule list before Emit reads the catalog. After `GetOrLower` returns, Count==0 is unreachable; if `GetOrLower` throws, the check never runs. Claim “Emit fail-closed if empty” is theater on the only call path that exists today. Reachability: **unreachable on valid and corrupt trees** once Lower returns.
- Suggestion: Delete the dead throw, or make Lower omit/clear catalog when the module is empty / Lower fails and add an oracle that strips catalog (or fails Lower) and asserts the throw. Prefer earlier detection: type the post-Lower session so Emit cannot see an empty catalog state.
- Status: open

### Issue 2 -- Severity: suggestion

- File: `src/Poly.DslCompiler/MinimalApiGenerator.cs:1131-1134` and `Poly.Tests/DomainModeling/Compile/SliceCProducerLoopCatalogTests.cs:140-144`
- Description: NoOp gate is `http is null && storage is null`. When http is null but storage is present, Contribute still emits Program.cs + demo.http (explicit harness comment). `SliceC_MinimalApiContributor_NoHttpBag_NoOps` only uses SampleDomain (neither bag) — test theater relative to the claim “NoOps without bags” / “no invent”. Load+successful http analyze still publishes HttpSurfaceMetadata, so Compile registration path likely always has http non-null; sibling remains for direct Contribute / `AddArtifactContributor`.
- Suggestion: Either fail-closed when http is null (harness must seed HttpSurfacePass / `uses http`), or rename claim/test to “NoOp only when both HTTP and storage bags absent” and add an oracle: persistence-analyzed domain, no http bag, `Contribute` → assert `[]` **or** document harness emit as intentional with a dedicated test name.
- Status: open

### Issue 3 -- Severity: suggestion
