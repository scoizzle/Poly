## Summary

The PR removes `UseThisReference` and retires the `BuildSubscriptionCaches` / `BuildPolicyBodies` side-lowering. `DomainProgramProjection.ToSyntax` now collects the entity-policy and subscription-handler nodes it puts on the type defs, and `RuntimeAnalysisCache` binds those same nodes, so simulate and print share one body for entity policies, subscriptions, and OnEntry/OnExit. The plumbing is sound: `WhenAnySimulatePrintAgreeTests` is a real oracle, and the `ActionResultType == null` fail-closed key is correct.

The PR has one systematic problem. Wherever simulate and print disagreed, it changed simulate to match print's existing tree without checking which side was right, and then rewrote the tests that encoded simulate's behavior. That regresses spread-set `when all` (a tracked plan item), flips `when any` against Scot's latest recorded decision, and turns unlinked to-one path-prefix into a fail-open. The store still keeps its own C# quantifier gate next to the new tree gate, and its comments now describe behavior the code no longer has.
