## F43 (bug, regression; new in this walk since 59601d4e)

- **Where**: `DomainExpressionLoweringPass.cs:429-441`. A `RelationshipNavigation` whose target is predicate-shaped (`IsPathPrefixPredicate`, `:199-205`: where-nav or path comparison) is not collected. Execution then **falls through** to `:440-441` and walks its children with the **outer** subject. So a value hop inside the predicate is collected on `this`.
- **Repro** (accepted by analysis):

  ```text
  Mentor: entity { Age: Number }
  Advisor: entity { Age: Number  mentor: Mentor }
  Customer: entity { Ready: Boolean default(true)  advisor: Advisor
    P: policy { Ready is (advisor where Age < mentor Age) } }
  ```

  Head prints `this.Mentor != null && this.Ready == (this.Advisor != null && (this.Advisor!.Mentor != null && …))`. The result is **CS1061** plus a simulate VM compile throw. If Customer also has an unrelated unlinked `mentor`, both sides silently return **False** where the answer is True. The form without parentheses behaves the same. **Master** prints `this.Ready == (this.Advisor != null && this.Advisor!.Age < this.Advisor!.Mentor!.Age)`, which compiles and gives True/True.
- A bare `advisor where Age < mentor Age` policy root is unaffected, and is correctly guarded at head.
- **Direction**: return early when `expr is RelationshipNavigation p && IsPathPrefixPredicate(p.TargetProperty)`, the same treatment as quantifiers. RN predicate lowering already guards the root hop, and the inner comparison's own walk guards the rest with the hop as subject. The head's `this.Advisor!.Mentor != null` output shows that guard works. Add this shape to `ForeignRootedHopAgreeTests`, then correct the comment.
