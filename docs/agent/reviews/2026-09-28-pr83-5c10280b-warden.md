## Findings

### G2: suggestion (hand-edit). The new `SourceEntityName` docs overclaim.
- **The docs**:
  - `LoweringContext.cs:80-82` reads "Entity whose members the current subject exposes. Path-prefix hops and quantifier bodies lower against the target entity."
  - `DomainExpressionLoweringPass.cs:64-66` says the same.
- **What the code does**:
  - `LowerAgainstEntity` (`:507-523`) swaps only `EnumPropertyNames` and `SourceEntityName`.
  - The nested pass inherits the source-scoped `PropertyTypeResolver`, `NavigationNameResolver` and `IsCollectionNavigation` from `_context`. These are built for the source entity: `EffectLoweringPass.cs:73-79`, `DomainToCSharpExporter.Actions.cs:470-472`.
  - The binder route (`:158-165`) keeps the outer name and enum map while the current subject is the peer parameter.
- **Why it matters**: a cold editor who trusts "lower against the target entity" will be surprised by G1.
- **The helper doc is accurate**: `LowerAgainstEntity`'s own doc (`:500-506`) says "(that entity's SourceEntityName and enum map)", which is right.
- **Direction**: the cheapest fix is to change the two docs to "relationship targets and enum literals resolve against the hop or quantifier target. Property-type and navigation resolvers stay source-scoped, and binder roots are not retargeted." The better fix is G1.

### G1: bug (pre-existing, same class as F1; follow-up). Two routes still lower target members with source-entity context.
- **Hop value leaf with a temporal add**:
  - Model: `uses temporal`; `Team: entity { Due: Date  Start: Date }`; `Dept: entity { Start: Date  team: Team  P: policy { team Due + 1 > Start } }`.
  - Simulate returns True. Print emits `this.Team!.Due + 1L > this.Start`, which fails with CS0019 (DateOnly + long).
  - Cause: `PropertyTypeResolver("Due")` asks `Dept`, so the temporal lowering doesn't fire.
  - Master `9db8868f` behaves identically. The mill found this (its Issue 1).
- **Binder-root enum compare**:
  - Model: `for lines as line invoke line.Mark(flag: line Kind == "Rush")`, where `Line.Kind: LineKind`.
  - Simulate sets `Flagged=True`. Print emits `target0.Kind == "Rush"`, which fails with CS0019 (LineKind vs string).
  - Master is identical.
- **Scope**: neither route is in the narrowed scope, and neither is a regression. I also missed the binder route last round.
- **Direction**:
  - In `LowerAgainstEntity`, rebuild the three resolvers for the target entity, as `Actions.cs:470-472` does for the root.
  - For binder roots, lower via `LowerAgainstEntity` with the binder's entity. Its target is known from the relationship or peer.
  - Add simulate+print agreement tests for both models.
