## Summary

The head does what it claims. `SourceEntityName` is explicit at every production construction site; a path-prefix hop now lowers its leaf against the hop target's name and enum map (`LowerAgainstEntity`), and quantifier bodies share the same helper, so nested resolution sees each successive target. `RelationshipNavigation` wraps a statement-bearing predicate leaf in `t = false; if (rel != null) { …; t = leaf.Value; }` so an unlinked to-one is false on both simulate and print. `previousStage` captures now come from the one shared `LocalNames` per method, so the stage-branch + entity-tail case no longer emits two `previousStage0` locals (CS0136).

The two c2265740 tests are genuine: the two-hop model puts a colliding `workers: many Temp` on **both** `Dept` and `Org` while `Team.workers` is `many Worker`, so a one-hop-only fix would still resolve on `Temp` and fail `CompileAndLoad`; the direct-hop enum model has `Dept.State: DeptState` and `Team.State: TeamState`, so a non-retargeted hop emits `DeptState.Done` against a `TeamState` and fails. Both would fail at `4b28ed3f` (which used `Route`, not `LowerAgainstEntity`, on hop leaves).

G1 remains, pre-existing, and every doc/comment this PR adds is honest about it: hop property-type/navigation/collection resolvers stay source-scoped, and binder roots keep the source name and enum map. No added doc, comment, or test name claims otherwise.
