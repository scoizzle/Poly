### F190 [suggestion] "Emit ignores the result today" is not what Emit does
`VmAnalyzerReportTests.cs:10`: "Emit ignores the result today, so the counts say how much would break if Emit started refusing VM errors." `DomainSession.cs:173-176`: `var interpAnalysis = TryAnalyzeForEmit(types); var generator = interpAnalysis is not null ? new CSharpGenerator(interpAnalysis) : new CSharpGenerator();`. The generator uses the analysis (variable types, dead-code elimination, per the doc comment on `TryAnalyzeForEmit`); Emit ignores only its Diagnostics. Say "Emit ignores the analysis's diagnostics today" (the plan's own H-section wording, `pipeline-convergence-plan.md:735`, has the same shortcut and can be tightened with it). Mill: kept as a nit; raised to suggestion because the gate counts a false comment.

### F191 [suggestion] "Most archived probes are old syntax or meant to be rejected" is false; the archive numbers in the PR body do not reproduce

Correct the numbers in the PR body before it becomes the squash message.
