## Fix list (100x, one PR)

1. **Policy namespace (B1, S9 part 2):** add action-local definitions to the redefinition and collision checks, make the exporter throw on a conflicting name instead of `continue`, fix the `CompletePolicyBodies` XML, and add the two fail-open probes as tests.
2. **MCP payload contract (B2, N1):** restore the per-kind `add` and `remove` payload shapes in guide section 12, make the smoke test assert them, and make `SelectGuide` try an exact number before a title substring.
3. **VM AST calls (B3, S5, S6, S7):** use one argument-init helper for `EmitAstNew` and `EmitAstInvoke` with a scalar→object ctor test, key the callable cache by `(node, mode)` and publish it only after compile succeeds, detect host jobs by structure, and decide reference vs scalar from types.
4. **One refuse path (S1):** a single `ThrowIfHasErrors` in `LowerToCatalog`; delete the inline block and the `Lower` duplicate; add an Emit refuse test.
5. **Runtime policy and host jobs (S2, S3, S4, N3):** gate stage policies on `!moduleOwnsRequire`; make every job fail loud on a non-DEI receiver and rename or re-doc the class; collapse the overload ladder or add a signature-binding test; delete the dead guards; add the trailing newline.
6. **Cache and docs hygiene (S8, S9 parts 1 and 3, S11, N2):** clear the stale analysis on a session switch; fix the `DomainModelAnalyzer` and `DslCompiler` comments; remove the unused `{stage}OnEntry`/`{stage}OnExit` names; use `Contains` in the evolution check and add the doc caveat.
7. **Docs links (S10):** rewrite the 33 moved-file links, the 20 inbound links and the 6 `.github/copilot-instructions.md` links, and run a link check.
