# Architectural Decisions

This directory contains high-level, cross-cutting architectural decisions that affect large parts of the Poly system.

## Purpose

These documents exist so that:

- Humans and AI agents working on the codebase can quickly understand major directional choices.
- Future work respects previously agreed constraints (especially around the domain model).
- We avoid repeatedly re-litigating the same big decisions.

**Start elsewhere for mechanisms:** Platform purpose, module boundaries, and “use this existing support, do not reinvent” live in **[`docs/CORE.md`](../CORE.md)**. This directory holds the *why* of major choices; CORE holds the *what to use*.

## Guidelines

- Only major, cross-cutting decisions should live here.
- Detailed or module-specific decisions should remain co-located with the code they govern (e.g. inside `Poly/DomainModeling/`).
- Keep entries concise and scannable. Link to more detailed records where they exist.
- Update `AGENTS.md` when adding new decisions that agents must be aware of.

**Note on Plans vs Decisions**: Execution is tracked in GitHub issues. Plans removed on 2026-11-10 stay in git history at `067bde75`.

## Current Decisions

- [2026-11-12: ActionScope — the module's one undo log](2026-11-12-action-scope.md) — R-08, theme R (#682) of epic #677: `Poly.Runtime.ActionScope` gives the lowered module a per-action frame — `Begin`/`Touch`/`Create`/`Commit`/`Rollback` over an `IActionScoped` entity or an `IDictionary<string, object?>` bag, with the storage port journaled through `IStorageJournal` — so a failed action restores every touched object in reverse touch order and then reverts the journal, and a nested failure aborts the whole action (Q1). Throws only on host misuse (Q3); no `Reset` and no poison state. Advances #677.
- [2026-11-12: The runtime contract package — kind→status table and concurrency token](2026-11-12-runtime-contract-package.md) — R-06, theme R (#682) of epic #677: `Poly.Runtime.DomainFailureStatus.Http(kind)` is the one kind→status table (Unique/Link/Conflict 409, Cascade 500 under a vetoable orchestrator ruling O-4, the other ten 400, unknown kind throws) and `Poly.Runtime.IVersioned { long Version { get; } }` is the optimistic-concurrency token P-09 binds. Keeps `Poly.Runtime` BCL-only, so the status is an `int`; P-14 deletes the generated host's failure-text parser. Advance #677.
- [2026-11-11: MCP surface finish — schema-derived argument validation and one typed error boundary](2026-11-11-mcp-surface-finish.md) — Q15, M-01 (#689) of epic #677: one pre-binder filter reads each tool's published `inputSchema`, so an unknown name, a wrong JSON type, or a missing workspace is `UNKNOWN_ARGUMENT` / `INVALID_ARGUMENT` / `WORKSPACE_REQUIRED`, and `INTERNAL_ERROR` means a defect; the hand-maintained allow-list is deleted and `ArgumentLimits` ships empty. Closes #533; part of #488 (array `steps` is M-07's).
- [2026-11-11: Domain type model and numeric rules](2026-11-11-domain-type-model-and-numeric-rules.md) — Q5/Q6, recorded from epic #659: transcribes Q5, Q6, OQ-3, OQ-6, OQ-11 verbatim; each rule is tagged ruling clause / #679 plan direction / Open; interim state per slice T-02…T-13. Provider of the `NumericRules` contract.
- [2026-11-11: Actor, principal, and library-provided policy evaluation](2026-11-11-actor-principal-and-policy-evaluation.md) — Owner ruling 2026-11-11 (SD12), transcribed: the principal is host-supplied and typed in `Poly.Runtime` (`Id`/`Roles`/`Claims`, threaded as one contributed parameter); `ActorMetadata` is an ontology record (principal key property + claim properties, no roles list, no `NodeFacts` row); `IPolicyEvaluator` is one synchronous `DomainResult<bool>` call in the lowered policy body (allow / deny / cannot-decide → `Policy`); `policy external` exists as an explicit `InlineBody | ExternalBody` union, never a nullable expression. Slices F-24/R-09 → F-25/F-26; advances #408.
- [2026-11-11: Checked arithmetic region](2026-11-11-checked-arithmetic-region.md) — Q6, recorded from epic #659: overflow **inside** a `checked` region is an arithmetic failure, **outside** it wraps; `Number / Number` is integer division (warning when assigned to `Decimal`); `Decimal -> Number` rounds only when analysis proves it safe, else an error. Slices F-06/F-07; closes #674 #624.
- [2026-11-11: Parameterised policies and parameter constraints](2026-11-11-parameterised-policies-and-parameter-constraints.md) — Q18, recorded from epic #659: a policy may take parameters (`CanWithdraw(amount)`), action parameters accept the same constraints as properties, and those constraints are checked **before** the action runs. Slices F-08/F-09; closes #503 #504.
- [2026-11-11: Key members are jointly unique; typed `Key` in generated C#](2026-11-11-key-members-jointly-unique-typed-key.md) — Q19, recorded from epic #659: `key(...)` members are jointly unique and enforced like `unique` (needs a storage library per Q8), mutability is deferred (members stay assignable), and generated C# keeps reference identity while gaining a typed `Key` for lookups, the storage port and routes. Slices F-12/F-13/F-14; closes #573 #405.
