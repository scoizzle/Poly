   ╔═════════════════════════  Execution — ProgramCompiler + Vm.Execute  ═════════════════════════╗
   ║   ProgramCompiler.Compile(bytecode.MicroOps)                                                 ║
   ║     ─→ generates LINQ Expression.Switch over PC values                                       ║
   ║     ─→ each case = compiled µop body (PushOp, AddOp, etc.)                                   ║
   ║     ─→ compiles to Action<VmState> delegate                                                  ║
   ║     ─→ cached: EnsureCompiled() on first call                                                ║
   ║            │                                                                                 ║
   ║            ▼                                                                                 ║
   ║   Vm.Execute(state)                                                                          ║
   ║     • Pre-load constants from Bytecode.Constants into Heap                                   ║
   ║     • prog.EnsureCompiled() (lazy)                                                           ║
   ║     • loop(state) — compiled dispatch, runs until Return                                     ║
   ║     • Extract result from stack top                                                          ║
   ║     • Supports suspend/resume: Int/Iret interrupts (vector=1)                                ║
   ║     • Breakpoints: BreakpointPCs HashSet, checked in dispatch                                ║
   ║            │                                                                                 ║
   ║            ▼                                                                                 ║
   ║   ┌────────────────────────────────────────────────────────────────────┐                     ║
   ║   │ VmState — runtime state:                                           │                     ║
   ║   │  • Stack (ValueStack): slot-based long[]                           │                     ║
   ║   │    Frame layout: [args][metadata: (returnPC<<32)|fb][locals][eval] │                     ║
   ║   │    FrameBase sentinel: -1 = top-level (no active frame)            │                     ║
   ║   │  • Heap: List<object?> + free-list (Stack<int>)                    │                     ║
   ║   │    Set(handle, null) reclaims slot; no tracing GC                  │                     ║
   ║   │  • PC, FrameCount, BreakpointPCs, Trace                            │                     ║
   ║   │  • InterpreterResult: Value (boxed) + Diagnostics                  │                     ║

 ╔════════════════════════════════════════════════════════════════════════════════════════════════╗
 ║   MODULE BOUNDARIES & DEPENDENCY RULES (enforced, one-way)                                     ║
 ╚════════════════════════════════════════════════════════════════════════════════════════════════╝

   Layer 0:  Syntax  ←──  all other modules (Syntax is the base layer — no deps on anything)
   Layer 1:  Interpretation ──→  Introspection
             Validation     ──→  Interpretation
   Layer 2:  Synthesis      ──→  Syntax, Interpretation (VM for macro validation)
   Layer 3:  DomainModeling ──→  Syntax, Interpretation, Synthesis (evolution loop)

   Key rules:
     • No module may depend on Synthesis except DomainModeling (evolution loop).
     • Introspection must NOT depend on Interpretation (CLR providers add types, not deps).
     • Domain concepts lower to generic VM opcodes only — no domain-specific opcodes.
       See docs/decisions/2026-06-08-domain-lowering-boundary.md


 ╔════════════════════════════════════════════════════════════════════════════════════════════════╗
 ║   KEY ARCHITECTURAL PROPERTIES                                                                 ║
 ╚════════════════════════════════════════════════════════════════════════════════════════════════╝

     • VM is CANONICAL SEMANTICS — all future backends must pass VmParityTests.
     • LinqExpressions tier is the test reference (may be removed).
     • µop-level tracing via VmTrace.LogUop — ~1ns when state.Trace is null (default).
       Active in all build configurations. TestTraceWriter routes to stderr.
     • AnalysisContext holds type defs, node metadata, and diagnostics.
     • Zero external dependencies in core (net10.0, only BCL).
     • The domain-as-macro principle: domain = macro that expands to generic IR at lowering time.
