# Emitted expression body: sieve (strided variant)

The body the VM emitter produces for `docs/perf-comparison/sieve_polyvm.cs`, rendered as an
indented expression tree. **This is a diagnostic artifact, not a test input** - it will drift as
the emitter changes, and that is expected. Regenerate with
`Poly.Tests/Interpretation/ExpressionBodyDumpTests.cs` (it writes `/tmp/expr-sieve-strided.txt`),
and the shared renderer is `Poly.Tests/TestHelpers/ExpressionText.cs`.

Regenerated 2026-10-23 for IS7h, `CompilationMode.NoDebug`.

Reading notes:

- `_slots` / `_heap` / `_fp` / `_this` are the fixed frame locals; `_regN` are variables;
  `_rN` are ring slots; `_iN` are **Int32** ring slots (IS7c) and `_dN` would be doubles.
- The buffer is a promoted array local (`_arr0`, `long[]`): the definition allocates once and
  binds both the local and the heap, and element access is `_arr0[i]` with no deref and no cast.
- **The strided mark loop contains zero `_heap.UnsafeGet` calls.** It used to contain two per
  iteration - one for the read and one for the write of `a[i] = a[i] | mask` - because
  `StridedSetBits` received the array as an argument and the array cache declined it. IS7h gave
  the intrinsic a promoted receiver, which took `sieve_polyvm.cs` from ~3,379 to ~2,995 us (min).
- `ExpressionBodyDumpTests` asserts all three facts above, so this file cannot rot silently.
