## Why this is next

A suite of Poly domains composed at `bind` only becomes a product if **hosts can register** new authoring, the same authoring can **round-trip**, analysis can **see** it, producers can **fill** `ImportedContract`, and artifact emitters can **export the composition root**.

Without a pack host, every next step forks core (`PolyDslParser`, `DomainDslPrinter`, default analyzer list, `DslCompiler` enums).

---

## Locks

1. **Parser and printer are one seam.** A pack that can be authored must print the IR it produced. `apply_dsl` and `export_dsl` share the same pack set. A parse-only pack is incomplete.
2. **That seam is `Poly.Grammar`.** A pack registers **patterns** on existing rules (`expr-primary`, `expr-primary-no-not`, `annotation`, …), **fold handlers** (match → IR), and a **print binder** (IR → rule + pattern name + content fills). Grammar `Matcher` recognizes; Grammar `Printer` emits. Do **not** add `IExpressionPrintForm` / string-concat print beside the table. `ExpressionFormRegistry` + `IExpressionPrimaryForm` are a **bridge to delete**, not the product pack API.
3. **Unprintable IR fails closed.** `ExpressionPrinter.Default()` emitting `?TypeName` is a bug. Pattern without binder, or IR without binder, fails at pack apply / print — never placeholder text. Same rule already locked for unknown annotation facets.
4. **Pack-owned slice, core-owned seam.** A pack owns its spelling **and** its resolved IR as a contained vertical slice (see the temporal pack: `Now`/`Today`/`DateOperation`/`Duration` + forms + binders all under `Poly/DomainModeling/Packs/Temporal/`, dispatched through the core `DomainExpression` seam). Core dispatch is **open**: `DomainExpressionDispatch<TResult>` falls through to an `ExpressionDispatchRegistry<TResult>` (ambient product-default set) for pack-owned subtypes, so core never imports a pack. Session without that pack: parse rejects the spelling; print of that IR already in the tree fails closed.
5. **Four optional hooks.** A pack contributes to some, not all:
   - **Parse + print** — Grammar patterns + fold handlers + print binders (annotations migrate onto the same table)
   - **Analysis** — type maps, storage conventions, extra passes
   - **Produce** — fill `ImportedContract` from a spec or another loaded `Domain`
   - **Artifacts** — files from the *analyzed* model (host/REST, `.http`, schema)
6. **No core keywords from packs.** Packs do not add `entity` / `action` / `bind` / `contract`. They add open forms and annotation keywords only.
7. **Packs do not invent product IR.** Producers emit `ImportedContract` + owned value types + endpoints. Hosts consume analysis + `ContractBinding`.
8. **Analysis is the hub.** Artifact code is not the first place a bad model dies.
9. **Do not extract `DomainToCSharpExporter`.** Shared program IR stays in core. Host artifacts (Minimal API, `.http`) may register on the artifact hook.
10. **One `IDomainPack.Apply`.** Not a 12-method plugin host. Duplicate pack id, duplicate annotation keyword, duplicate pass name → fail closed.
11. **Split files when a domain is too big for one agent / team / deployable.** Composition root export is the public API; children are not unioned onto the route table.
12. **`DomainDslPrinter` becomes the IR walker, not the spelling owner.** It chooses `(rule, pattern)` and fills `Value` positions. Keyword/operator text comes from `DslGrammar.CanonicalText` via `Printer`. Pack forms never hard-code `assign` / `days` / `Now` in a private printer.
13. **If the engine cannot express a form, evolve Grammar in this suite.** Residual RD (`IExpressionPrimaryForm` only) must cite the missing engine feature. Do not grow `DslExpressionParser` method trees for pack sugar.
14. **Whitespace is the TokenWriter.** `DslTokenReader` skips spaces/comments; the inverse is `DslTokenWriter` (existed, deleted at grammar v2 cutover as unused — bring it back). Grammar `Printer` emits **tokens** (kind + text) into a writer, not concatenated `CanonicalText`. The writer inserts the separators the reader would skip (space between two word tokens; product rules like space after `:`). Binders never emit spaces. Indent / newlines are later writer modes (`EnterBlock`), not a second layout object. `DslLayout` is not a type.

## Shape

```text
IDomainPack.Apply(PackContext)
                │
                ├─ Grammar contributions (THE parse/print API)
                │     Define(rule).Pattern(name)…     ── Matcher
                │     Fold handler match → IR
                │     Print binder IR → (rule, pattern, fills)
                ├─ DomainInputBuilder
                │     Annotations (migrate toward annotation patterns)
                │     TypeMaps / conventions / extra passes
                ├─ ContractProducerRegistry   (wave 4)
                └─ ArtifactContributorRegistry (wave 5)

Host builds one Grammar = DslGrammar.Build(pack contributors)
  apply_dsl  → Matcher + handlers on that Grammar
  export_dsl → walker + Printer on the SAME Grammar
  compile    → analyze → artifact contributors
```

```text
Domain / DomainExpression
        │  print binder (core + pack)
        ▼
 (rule, pattern, content)
        │  Grammar.Printer + layout
        ▼
 .poly text     ──round-trip──►  Matcher → same IR
```

Core expression subtypes that already have table patterns (`number`, `ident`, `plus`, …) should print through that binder as soon as layout exists. Pack binders run first for IR they own (`DateOperation` → temporal patterns).

## Engine gap (wave 1 must close)

`PrinterTests.Print_DslEntityPattern_SkeletonPlusValue` is the hole: `Print("top", "entity")` → `:entity`. Product text is `Order: entity`.

That is not a binder problem and not a new layout type. The reader already threw the spaces away. The writer puts them back.

```text
Printer ── tokens (kind, text) ──► ITokenWriter
                                      │
                         DslTokenWriter (language)
                         last-kind + next-kind → space or not
```

**Phase 1 writer (thinnest):**

- `[NEW]` `ITokenWriter<TToken, TTokenKind>` in `Poly.Grammar` (or revive the deleted name). `Write(kind)` / `Write(kind, text)` / `ToString()`.
- `[MODIFY]` `Printer` to write through it. `CanonicalText` remains kind → lexeme, not kind → lexeme+space.
- `[NEW]` `DslTokenWriter` in DomainModeling.Parsing — inverse of `SkipWhitespaceAndComments`: space between two word tokens (keyword / ident / number / string); space after `:` before a word; punctuation attaches as locked in tests.
- Binders / `PrintContext` emit values only (`Order`, `12`). No `" "`.
- Skeleton tests that pin `:entity` move to “writer off / raw printer” **or** update to the product spacing once the writer is the default DSL emit path.

Indent, blank lines, and entity sort stay on the IR walker until a later `EnterBlock`/`Newline` on the same writer. Do not invent `DslLayout`.

## Phases

One CURRENT suite at a time. Each phase is its own admit.

```text
1  DSL Grammar     TokenWriter · Printer emits tokens · print binder · pattern round-trip
2  Pack surface    IDomainPack · PackSet · MCP/compiler share one Grammar
3  Built-in packs  temporal → InternalDomain producer → root host artifacts
                   (re-home Sqlite/SqlServer onto IDomainPack as the first Apply consumers)
```

Phase 3 does not start until a pack can register a pattern and have it parse **and** print without touching `PolyDslParser` / `DomainDslPrinter` dispatch.

### Phase 1 — DSL Grammar (was wave 1)

**Outcome:** A pack extends `DslGrammar` with a named pattern; Matcher parses it; `Printer` + binder reprints it; unprintable IR is loud. No new string-print interface.

| Touch | Change |
|-------|--------|
| `[NEW]` `ITokenWriter` + `[NEW]` `DslTokenWriter` | Inverse of `DslTokenReader` whitespace skip. Printer emits tokens; writer owns spaces. |
| `[NEW]` print binder registry | IR → `(rule, pattern, fills)`. Pack + core register here. Duplicate IR owner fails closed. |
| `[MODIFY]` `Parsing/DomainDslPrinter.cs` | Expression print: binder + `Printer` first; `Default()` throws. Ctor takes the same Grammar / parser inputs as parse. |
| `[MODIFY]` `ExpressionFormRegistry` | Stop being the product API. Grammar contributors + binders only. Leave RD `IExpressionPrimaryForm` as cited-gap escape (tests must name the engine hole). |
| `[MODIFY]` `Poly.Tests/Grammar/DslExpressionE1Tests.cs` | `MAGIC` / `N unit` become **pattern** registrations on both primaries; parse + print + reparse. |
| `[NEW]` fail-closed tests | `DateOperation` without temporal binder throws; pattern without binder rejected at apply |

**Exit:** Pack-shaped E1 forms round-trip through Grammar `Printer`. `?DateOperation` is gone. Guide unchanged (no `Now` yet).

**Not this phase:** product temporal spelling; rewriting entity/stage pretty-print; deleting `DomainDslPrinter`; `IDomainPack`.

### Phase 2 — Pack surface (was wave 2)

**Outcome:** `IDomainPack` is real because three persistence packs already exist.

| Touch | Change |
|-------|--------|
| `[NEW]` `Poly/DomainModeling/Packs/IDomainPack.cs` | `string Id { get; } void Apply(PackContext ctx);` |
| `[NEW]` `PackContext` / `PackSet` | Apply in order; duplicate `Id` fails |
| `[MODIFY]` `DomainInputBuilder` | `AddPack(IDomainPack)` |

| `[MODIFY]` `DslCompiler.cs` | Pack list / `PackSet` instead of `DbmsPack` as the model (`--dbms` may remain a convenience alias that selects a pack) |
| `[MODIFY]` MCP session | Hold `PackSet`; `apply_dsl` + `export_dsl` use it (Sql annotation pack stays the default product set) |
| `[MODIFY]` CORE + this plan status | Host is the compose point |

**Exit:** Sqlite and SqlServer compile paths behave as today. Adding a pack is `AddPack`, not a new enum arm. Parse and print still share the set.

**Not this phase:** new product DSL; contract producers; moving Minimal API. Re-homing Sqlite/SqlServer **is** this phase — they are the first `Apply` consumers, not new capability.

## Negative tests (host)

- Pattern without print binder (or RD form without cited engine gap) → `AddPack` / `Build` fails.
- Print `DateOperation` with no temporal pack → fail closed.
- Unknown annotation facet → fail closed (already).
- Duplicate pack id / annotation keyword / pass name → fail closed.
- `export_dsl` without the parse-time pack set must not be possible on the product MCP path (one session set).
- Artifact contributor that ignores analysis diagnostics → not allowed (compile already fails closed on structural analysis).
