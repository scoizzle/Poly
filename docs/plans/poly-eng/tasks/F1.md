## Done when
A `DomainFunction` with parameters, a `DomainTypeReference` return type, and a single `DomainExpression` body lives on `Domain.Functions`, prints as `function Name(p: Type): Type = expr`, and round-trips through `AddFunctionChange` / `DomainEvolution.Apply`: the new root has the same name, parameter names and types, return type name, and body, and the original domain is untouched. `git grep 'record DomainFunction' -- Poly/DomainModeling/Ontology` finds the record. `"function"` remains in `_unsupportedKeywords`. Full suite green.
## SHIP if / NOT SHIP if
SHIP if the evolution round trip is lossless and the printer emits `function Name(...): Type = expr` for an API-built function.

NOT SHIP if the body is a statement list, effect list, or block rather than one `DomainExpression`; if `new Domain(name, types)` gains a third ctor argument; if the parser or `_unsupportedKeywords` changes; if a call expression, uniqueness check, or lowering appears; if a new visitor/interface/factory appears; or if a print-then-parse test is required for green (that is F2).
