## Scope
`SeenAt > Now - 60 Minutes` lowers to `DateTime.UtcNow.AddMinutes` of a negative long. `AddMinutes(long)` does not resolve, because `double.IsAssignableFrom(typeof(long))` is false. Analysis keeps the call (`IsNumericWidening` in `SyntaxTypeCompatibilityAnalyzer`). `ClassifyInvoke` then returns Unknown (`ValueRepresentationPass.cs:239-249`). The comparison requires both sides `HeapRef` (`DirectVmAbiEmitter.Expressions.cs`, `CompileCompareTest` / `EmitComparisonValue`). The property is `HeapRef` and the invoke is Unknown, so the VM compares ring handles. `SeenAt = UtcNow` against `Now - 60 Minutes` returns false. `SeenAt > Now + 60 Minutes` is also false, which matches the real answer, so the plus case looks fine. Assign works because it stores the boxed return, not a comparison.

Checked on master `06844e39`. `ClassifyTypeDefinition` (`:305-327`) already marks a non-long value type `HeapRef`.
