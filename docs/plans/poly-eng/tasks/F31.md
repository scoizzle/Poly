## Scope
`create in sessions { Token: "t" ExpiresAt: Now + 30 Minutes }` dies in the VM with `cannot tell whether argument … is a scalar or a reference`. `ArgumentIsStackScalar` (`DirectVmAbiEmitter.Invoke.cs`) returns false for `HeapRef` and throws when the representation is Unknown and `GetResolvedType` is null. The comment in `AddCreateNavMethod` (`DomainToCSharpExporter.Notify.cs:163-165`) says an untyped `Parameter` does not resolve, so the VM cannot tell scalar from reference.

A previous attempt returned true from `ArgumentIsStackScalar` for a value-type invoke and then hit `Member 'IsSuccess' is not resolved`. That attempt was reverted. DateTime is a heap value. This card does not edit `ArgumentIsStackScalar`.

If F26 classifies `AddMinutes` as `HeapRef`, this initializer can pass with no further product edit. Prove that. If it does not, stop.
