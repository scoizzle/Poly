## `CompletePolicyBodies`
Kept. `EvaluatePolicy` reads `RuntimeAnalysisCache.PolicyBodies` through `TryGetPolicyBody`, and `CompletePolicyBodies` builds that map. It adds only names the module did not emit, in practice the `not_X` names from `require not X`. Those are evaluated only on the simulator's fallback for an action without a module method. With `GetOrLower` storing the module's map directly, the full suite stays green (3415/3415), so no test exercises those extra bodies. Deleting it changes that untested fallback path, which is out of scope for a closure with no change. That is evidence for K2 or C8d, not a K4 change.
