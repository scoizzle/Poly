## Shape
- Syntax `equals(literal)`, same call form as `pattern("…")`, `length(n)` and `default(value)`. The literal is a string, a signed integer (`long`), a signed decimal (`double`), or `true`/`false`. Identifiers, `null` and empty arguments are parse errors.
- `equals` is a new keyword with `DslTokenKind.Equals`. That kind used to be what the tokenizer returned for `default`, while `CanonicalText(Equals)` was already `"equals"`. `default` now has its own `DslTokenKind.Default`.
- The printer prints `equals(<literal>)` with the same literal printer as `default(...)`. An API value that is an integral `double` (`5.0`) prints as `5` and parses back as `long` 5. Simulate and the printed C# compare numbers by value, so the meaning is unchanged.
- No analysis, lowering or export change. The exporter, simulator and Minimal API generator already handle `EqualityConstraint`.
