## Scope
- `SessionBuilder.Load` records only authored ids and seeds their primitives (`Poly/DomainModeling/Compile/SessionBuilder.cs:37-43`); `LoadCore` is the existing implicit-load pattern (`:45-52`). The three assembly paths are `DomainSession.ForExtensions` (`Poly/DomainModeling/Compile/DomainSession.cs:133-149`), `ForAuthoringDocument` (`:166-186`) and `DslCompiler.OpenCompileSession` (`src/Poly.DslCompiler/DslCompiler.cs:279-298`).
- `temporal` is still a product seed: `ExtensionCatalog.TemporalId` (`Poly/DomainModeling/Compile/ExtensionCatalog.cs:12`) appears in `ProductLanguage` (`:16`) and `ProductAuthoring` (`:19`), and `DomainFactory.Create` writes `ProductLanguage` onto every bootstrapped domain (`Poly/DomainModeling/Ontology/Bootstrap/DomainFactory.cs:24,37,61`).
- `DomainDslPrinter.Print` loops every `domain.Extensions` and emits a `uses` line (`Poly/DomainModeling/Language/DomainDslPrinter.cs:71-76`), so a domain that still records `temporal` prints it today.
- `DomainResolver.EnsurePrimitivesOnce` seeds every loaded library's `PrimitiveSeeds` (`Poly/DomainModeling/Language/DomainResolver.cs:134-148`); `AddDomainExtensionChange.ApplyTo` seeds them again for an authored id (`Poly/DomainModeling/Evolution/DomainChange.cs:677-694`). Both paths stay.
- After S1, Load always gives a session temporal meaning; only a raw `SessionBuilder` that never calls `LoadTemporal()` can omit it, and that is where the existing pack-absent fail-closed tests move.

- `SessionBuilder.LoadTemporal()` is added beside `LoadCore`: it constructs `new TemporalLibrary()`, calls the same `Register` path (so it adds `(PipelineStage.Load, "temporal")`), seeds `library.PrimitiveSeeds`, and does **not** append `temporal` to `_loadedIds`. `Load` keeps its existing behavior. Extract the primitive-seed loop only if it keeps both methods one loop each.
- `DomainSession.ForExtensions`, `DomainSession.ForAuthoringDocument` and `DslCompiler.OpenCompileSession` call `builder.LoadTemporal()` after `LoadCore()` when the id list they are about to load does not already contain `ExtensionCatalog.TemporalId`.
