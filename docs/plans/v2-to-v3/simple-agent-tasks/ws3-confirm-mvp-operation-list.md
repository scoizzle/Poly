# Micro-Task: Confirm and Lock MVP Operation List for Phase 1

**Parent Workstream**: WS3 - MVP Operation Support  
**Difficulty**: Small Model Friendly (coordination / documentation task)  
**Estimated Context**: Low

## Objective
Produce a clear, agreed-upon list of the exact operations that will be supported in the first milestone of the evolution layer.

## Context You Must Read First

- The "Proposed MVP Scope" section in `workstreams/ws3-mvp-operations.md`
- The roadblock documents (to ensure we cover at least one real pain point)
- The PersonLifecycle examples (to ensure we can prove the new model)

## Exact Steps

1. Review the suggested operations in the workstream file.

2. Cross-reference against the three real demos and the documented roadblocks.

3. Propose a final locked list of 5–8 operations for the first milestone, including:
   - Must-have operations for the proof scenarios
   - Nice-to-have operations that are low effort

4. Document any operations that are explicitly out of scope for the first milestone and why.

5. Create or update a decision record (or section in the Phase 1 plan) with the locked MVP scope.

## Verification

- [ ] A clear, prioritized MVP operation list exists
- [ ] It is referenced from the master roadmap and WS3 workstream
- [ ] The list enables at least one real roadblock to be demonstrated

## Output

- Locked MVP operation list (as a document or section in the plan)
- Any supporting decision record
- Update to parent workstream
