# Micro-Task: Audit One Workstream Against Core Engineering Principles

**Parent Workstream**: WS6 - Documentation & Decision Hygiene  
**Difficulty**: Small Model Friendly  
**Estimated Context**: Low

## Objective
Review one Phase 1 workstream file (e.g. WS1, WS2, or WS3) against the six Core Engineering Principles and produce a short gap analysis.

## Context You Must Read First

- `docs/decisions/2026-core-engineering-principles.md` (the six principles)
- The target workstream file (e.g. `workstreams/ws1-evolution-layer-core.md`)

## Exact Steps

1. Read the six principles carefully.

2. For the chosen workstream, go through each principle and note:
   - Where the workstream already aligns well
   - Any potential violations or risks
   - Suggestions for improvement

3. Write a short, constructive audit note (1-2 pages max).

4. Submit it via an agent summary (or attach it to the workstream).

## Verification

- [ ] The audit is balanced and references the principles by name
- [ ] It is constructive rather than critical
- [ ] It is saved and linked from the relevant workstream

## Output

A short audit document for one workstream.
